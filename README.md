# Detección de Fraude con Machine Learning

Este proyecto aplica técnicas de ciencia de datos y machine learning para detectar posibles casos de fraude mediante el análisis de datos y la comparación de modelos predictivos.

## Objetivo

Desarrollar un modelo capaz de identificar patrones asociados a transacciones fraudulentas, utilizando técnicas de procesamiento de datos, entrenamiento de modelos y evaluación mediante métricas de rendimiento.

## Tecnologías utilizadas

- Python
- Google Colab / Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- XGBoost
- Redes Neuronales

## Modelos aplicados

- XGBoost
- Redes Neuronales
- Modelos de clasificación supervisada

## Proceso del proyecto

1. Carga del dataset.
2. Limpieza y preparación de datos.
3. Análisis exploratorio de datos.
4. División de datos en entrenamiento y prueba.
5. Entrenamiento de modelos.
6. Evaluación de resultados.
7. Comparación del rendimiento de los modelos.

## Métricas de evaluación

- Accuracy
- Precision
- Recall
- F1-score
- Matriz de confusión

## Conclusión

El proyecto permite comparar el desempeño de diferentes modelos de machine learning para la detección de fraude, identificando cuál ofrece mejores resultados según las métricas evaluadas.
